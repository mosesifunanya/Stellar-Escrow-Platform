# StellarChain

A decentralized escrow platform built on the Stellar network using Soroban smart contracts.

StellarChain allows users to securely manage payments between payers and workers without relying on a traditional middleman.

## Features

- Create and manage escrow agreements
- Milestone-based payments
- Release milestone payments
- Open and resolve disputes
- Refund expired escrows
- Cancel active escrows
- Stellar wallet connection
- Responsive dashboard
- Dark and light mode

## Tech Stack

-Stellar
-Soroban
-Rust
-React
-Vite
-Node.js
-Express
-TypeScript
-Stellar Wallets Kit

## Smart Contract

The Soroban smart contract handles escrow creation, payments, disputes, refunds, and cancellations.

Deployed on Stellar Testnet.
